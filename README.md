# 🛡️ A股排雷技能

基于 **2024年沪深交易所《股票上市规则》** 的财务风险评分体系，助你提前识别ST/*ST风险。

## 📌 功能特性

- **全自动分析**：输入股票代码，自动抓取年报财务数据
- **13维风险评估**：覆盖财务、审计、内控、规范、监管全维度
- **实时ST预警**：基于最新退市规则，提前识别风险
- **零误杀验证**：优质龙头股（茅台、招行等）全部0分通过

## 🎯 风险评分体系

### 七大风险维度

| 类别 | 风险项 | 评分 | 说明 |
|:---:|--------|:---:|------|
| **财务类** | 净资产为负 | +4 | 资不抵债 |
| | 营收不达标 | +2 | 主板<3亿/创业板<1亿 |
| | 连续亏损 | +1~3 | 每多亏1年+1分 |
| | 毛利率恶化 | +1 | 下降超5个百分点 |
| **审计类** | 无法表示意见 | +3 | 审计非标 |
| | 保留意见 | +2 | 审计非标 |
| | 强调事项段 | +1 | 审计非标 |
| **内控类** | 内控否定意见 | +3 | 治理缺陷 |
| | 连续两年内控非标 | +2 | 递进风险 |
| **规范类** | 资金占用≥2亿/30% | +4 | 大股东占款 |
| | 资金占用≥1000万/5% | +2 | 轻度占款 |
| | 银行账户冻结 | +3 | 资金链紧张 |
| | 违规担保 | +2 | 治理问题 |
| **分红类** | 分红不达标 | +2 | 具备能力但不分红 |
| **交易类** | 股价<2元 | +2 | 接近1元退市线 |
| | 市值<5亿 | +3 | 微型股风险 |
| **监管类** | 造假认定 | +5 | 行政处罚认定 |
| | 造假金额达标 | +6 | 1年≥2亿且≥30%等 |
| | 处罚告知 | +4 | 行政处罚事先告知 |
| | 立案调查 | +3 | 证监会介入 |

### 风险等级划分

## 📋 ST/*ST触发规则速查

### 财务类（直接触发*ST）

| 条件 | 主板 | 创业板/科创板 |
|-----|:---:|:---:|
| 净利润为负+营收< | 3亿 | 1亿 |
| 净资产 | <0 | <0 |
| 审计意见 | 无法表示/否定 | 无法表示/否定 |

### 规范类（触发ST）

- 资金占用≥2亿或净资产30%，整改不力
- 内控连续两年非标
- 主要银行账户冻结

### 重大违法类（立即ST）

- 行政处罚认定造假，无论金额大小
- 造假金额达标（1年≥2亿且≥30%）直接退市
